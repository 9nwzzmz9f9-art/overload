# Overload

A single-user strength-training tracker with a deterministic progression
engine — not a coach, not an AI app. It tells you exactly what to lift
next; you log reps; it decides on its own whether each set's weight goes
up next session.

Plain HTML / CSS / JavaScript. **No build step, no dependencies, no
networking.** Installable as a PWA; every byte of data lives in the
browser's IndexedDB on the device that entered it. See
[`SPEC.md`](SPEC.md) for the full product spec and
[`CLAUDE.md`](CLAUDE.md) for the working rules.

## Run locally

```
python3 -m http.server 8743
```

Then open <http://localhost:8743>. (Any static file server works — there
is nothing to compile.)

## Tests

Pure-logic modules (session-plan interleaving, the progression engine,
plate math, rest-timer math, resume-position logic, workout stats) have
unit tests using only Node's built-in runner:

```
node --test tests/
```

## Deploy

The repository root **is** the site — deploy it as-is. On Cloudflare
Pages: framework preset **None**, build command **empty**, build output
directory **`/`**.

Because all data is device-local with no sync, the app URL is effectively
the account: data does not move between origins. Pick the production URL
before entering real data, install it to the home screen for durable
storage, and use **Settings → Backup** to export regularly.

## Layout

- `index.html`, `manifest.json`, `sw.js` — the PWA shell
- `css/style.css` — the whole stylesheet
- `js/` — ES modules, no bundler:
  - `db.js` / `repository.js` — IndexedDB and the domain data API
  - `sessionPlan.js`, `progressionEngine.js`, `plateCalculator.js`,
    `restTimer.js`, `workoutProgress.js`, `workoutStats.js` — pure logic
  - `dataExporter.js` / `dataImporter.js` — backup / restore
  - `migrations.js` — one-time device-local data migrations
  - `screens/` — one module per screen
- `js/data/exercise-library.json` — bundled, trimmed `free-exercise-db`
  (public domain); regenerated by `tools/build_exercise_library.py`
- `tests/` — unit tests
